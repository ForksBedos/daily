# Образцы постов для генератора (этап 7)

Сюда СММ кладёт 3–5 удачных постов на каждую площадку: по файлу на пост, в папку с кодом площадки из `config/posts.yaml`.

```
config/post_examples/
├── telegram/
│   ├── 01.md
│   └── 02.md
├── linkedin/
├── threads/
└── instagram/
```

- Файл — текст поста как есть, с хэштегами и ссылкой, на любом из языков.
- Образцы попадают в промпт Claude целиком и задают голос компании: длину абзацев, эмодзи, подпись, хэштеги.
- Факты из образцов в новые посты не переносятся: Claude берёт факты только из статьи дайджеста.
- После добавления или правки образца посты по темам делаются заново: старые ответы из кэша не берутся.

Пока папки пусты, посты пишутся только по правилам из `config/posts.yaml`.
