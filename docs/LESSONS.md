# Уроки из ошибок

Одно место, где записано, на чём обожглись и что из этого сделали. Ошибки продукта — в `docs/ISSUES.md`, здесь — ошибки работы.

Правила записи:
- Строка без вывода не считается: урок без изменения — это история.
- Вывод бывает трёх видов: тест или хук (работает сам), правило (нужна дисциплина), решение владельца.
- Ошибка повторилась — не новая строка, а усиление старой: правило заменить тестом или хуком.
- Разбираем систему, а не виноватых.
