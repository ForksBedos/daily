# Этап 11. Дальнейшее развитие

Это не обязательства, а список идей, который команда приоритизирует после запуска бота (этап 10).

## Посты и бот
- **Публикация прямо из бота** в Telegram-канал: только после явного подтверждения человеком. Позже, через их API, — LinkedIn и Threads.
- **Картинка к посту** — карточка с заголовком в фирменном стиле. Нужна для Instagram, где пост без картинки невозможен.
- **Пожелание к посту** свободным текстом, например «акцент на малый бизнес». Передаётся Claude как пожелание пользователя, факты по-прежнему только из статьи.
- **Пост по нескольким темам** («главное за неделю») и **дайджест-пост** дня.
- **Новые площадки:** Facebook, X. Добавляются профилем в `config/posts.yaml`.
- **Дайджест за прошлую дату**, выбор из календаря.
- **«Выключить / включить источник»** у админа — если в работе такая потребность подтвердится.
- **Уведомления админу:** источник не отвечает несколько дней подряд, скоро истекает токен Claude.

## Источники
- **Telegram-каналы** через публичный предпросмотр `t.me/s/{канал}`, без ключей. Нужен список каналов от команды.
- **Сайты с собственными адресами:**
  - Таможенный комитет (customs.uz), Агентство статистики (stat.uz). На gov.uz их нет;
  - Агентство по управлению госактивами;
  - биржа (uzse.uz).
- **На gov.uz по запросу:** госзакупки (`icppa`), другие ведомства.
- **regulation.gov.uz не подключаем:** robots.txt запрещает обход полностью.

## Качество
- **Многоязычные эмбеддинги** (`multilingual-e5-small`, работает на CPU, около 0,5 ГБ памяти) для дедупа. Нужны, если перефразы проскакивают мимо правил и Claude.
- **Автоматическая проверка ссылок:** все ссылки дайджеста и постов отвечают 200.
- **Обучение на оценках:** «👎» и выбранные «другие варианты» помогают подобрать образцы для промпта постов.

## Инфраструктура
- Git и общий репозиторий — когда команда решит.
- Перенос `outputs/` в OneDrive или на сетевой диск: путь меняется в `settings.yaml`.
- Запуск на постоянно включённом компьютере вместо ноутбука. Бот тогда отвечает и ночью, и в выходные.
