# Этап 4. Сверка законов с lex.uz

**Цель.** У каждой правовой новости в дайджесте есть статус сверки с lex.uz и ссылка на документ на языке файла. Новости, опередившие публикацию акта, перепроверяются в следующие дни.

**Оценка:** 2 дня. **Зависит от:** этапа 2 (`legal_acts` из RSS, `doc_key`) и этапа 3 (`item_legal_refs`).

---

## Что выяснено (02.11.2026)

- **RSS lex.uz неполный и опаздывает.**
  - 89 актов за месяц.
  - ПКМ № 594 от 28.10.2026 (о нём 02.11 пишет norma) в ленте ещё нет.
  - Среди номеров ПП за месяц есть 358–359, 368, 371, 373–375, 378–380, 387. Остальные номера между ними отсутствуют.
  - Вывод: одной ленты мало, нужен поиск.
- **Поиск lex.uz работает обычным HTTP-запросом, JavaScript не нужен.**
  - Пример: `https://lex.uz/ru/search/nat?query=ПП-387`.
  - В выдаче ссылки `/ru/docs/{id}?query=…` и строки вида «Постановление Президента Республики Узбекистан, от 27.10.2026 г. № ПП-387».
  - **В выдаче бывают акты других лет с тем же номером:** ПП-387 от 26.12.2025 и ещё 6. Сопоставлять нужно по виду, номеру **и** году.
  - Robots.txt у lex.uz нет (404), ограничений на обход нет.
- **Страница документа `/ru/docs/{id}`.**
  - В блоке `docHeader` есть вид, издатель, дата, номер и «Дата вступления в силу».
  - Есть ссылка на **оригинал на узбекском**: другой `id` (для ПП-387: ru 8559901 → uz 8559898), подпись «узбекском языке».
  - Текст документа подгружается скриптом. Он нам не нужен: достаточно реквизитов и ссылки.
- **Английские версии.** `lex.uz/en/docs/{id}` открывает тот же документ, отдельного английского перевода по этому адресу нет. Переводы на английский у lex.uz редки, поэтому в английском дайджесте ставим русскую ссылку с пометкой «(in Russian)».
- **Как искать вид, которого нет в виде кода.** Для ПКМ и ведомственных актов формат запроса (`"постановление Кабинета Министров 594"` или фильтр по виду) **нужно проверить при реализации**: просто номер 594 даст слишком много результатов.

## Процесс сверки

Для каждого `doc_key` из `item_legal_refs` материалов окна:

1. **Справочник.** Ищем `legal_acts` по `doc_key`. Если нашли, статус `verified`.
2. **Черновик.** Если у упоминания стоит флаг `is_draft`, ставим статус `draft` и дальше не проверяем.
3. **Поиск.** Иначе ищем на lex.uz. Ответ кэшируется в `lex_lookups` на 24 ч, между запросами пауза ≥ 1 с. Разбираем выдачу и сопоставляем вид, номер и год.
   - Нашли — upsert в `legal_acts` с `source=lex_search`, статус `verified`.
   - Не нашли — `pending`.
4. **Страница документа.** Для подтверждённых актов без даты вступления в силу или без `uz_lex_id` скачиваем страницу один раз и дописываем реквизиты (`source=lex_page`).
5. **Перепроверка.** `pending` перепроверяются в каждом дайджесте 7 календарных дней. Через 7 дней статус становится `not_found`, материал помечается для ручной проверки.
6. **Обновления.** Если акт, уже вышедший в дайджесте как `pending`, стал `verified`, он попадает в блок «Обновления» (этапы 3.5 и 6).

## Ссылки по языкам

Уточнено при реализации (см. «Итоги реализации»): у английских переводов и у узбекской латиницы свои id.

| Файл | Ссылка | Если версии нет |
|---|---|---|
| ru | `https://lex.uz/ru/docs/{lex_id}` | узбекская (у свежих ПКМ первые дни есть только она) |
| uz | латиница `https://lex.uz/uz/docs/{uz_latn_lex_id}`, иначе кириллица `https://lex.uz/docs/{uz_lex_id}` | русская |
| en | `https://lex.uz/en/docs/{en_lex_id}` | русская с пометкой «(in Russian)», затем узбекская |

Ссылку и язык документа по ней возвращает `lex_doc.act_link(act, lang)`. Если язык документа не совпадает с языком файла, дайджест ставит пометку.

- Процесс:

  - нигде нет → `pending`, а через 7 дней `not_found`;
  - проект → `draft`.
- Кэш: повторный запрос в течение 24 ч не идёт в сеть.

- Сверка всех правовых кластеров дня занимает меньше 1 минуты.

### Формат поиска (задача 6)
Поиск по номеру акта: `https://lex.uz/ru/search/nat?actnum={номер}&…&fyear={год}`. Параметры взяты из формы расширенного поиска lex.uz.

| Вид | Параметры кроме `actnum` и `fyear` |
|---|---|
| ЗРУ | `form_id=3968` (закон; конституционные законы тоже находятся) |
| УП | `form_id=3973&body_id=19123` (указ, Президент) |
| ПП | `form_id=3972&body_id=19123` (постановление, Президент) |
| РП | `body_id=19123`: с `form_id=588` (распоряжение) поиск по номеру ничего не находит |
| ПКМ | `form_id=3972&body_id=819` (постановление, Кабинет Министров) |
| МЮ | `actnum=1010-2&regnummj=1`, без года: номер регистрации в Минюсте уникален |
| Сенат, суды | не ищутся, только справочник из RSS (`find_refs` их и не извлекает) |

- `query=594` ищет по всему тексту и находит 1349 документов. `query=ПКМ-594` не находит ничего.
- Без `fyear` у ПКМ № 8 выходит 66 строк, по одной на год и язык, а на странице выдачи их только 20. Поэтому год в запросе обязателен.
- **Язык не ограничивается.** Выдача содержит отдельные строки для русской, узбекской (кириллица и латиница) и английской версий, у каждой свой id. Строки реквизитов разбираются на русском и узбекском. Английские строки («Resolution of the President …») пропускаются.

### Решения, принятые по ходу работы
- **Узбекский оригинал = акт опубликован.**
  - ПКМ № 594 (28.10) и № 596 (29.10) на 02.11 есть на lex.uz только на узбекском. Русский перевод появляется через несколько дней: у приказа МЧС рег. № 3963 узбекский id 8554321, русский 8560353.
  - Поиск только по-русски дал бы ложный `pending` самому упоминаемому акту недели: ПКМ № 596, 5 материалов.
  - Такие акты получают статус `verified`. Русский дайджест ссылается на узбекскую версию.
- **Версии по языкам.**
  - Берутся из строк выдачи и из переключателя языков на странице документа (подписи «На русском», «Ўзбекча», «O'zbekcha», «In english»).
  - Знак id не означает алфавит: у ПП-387 латиница −8559898, а у МЮ 1010-2 кириллица −8561230.
  - В `legal_acts` три новые колонки: `uz_lex_id` (кириллица), `uz_latn_lex_id`, `en_lex_id`.
- **Английские переводы на lex.uz есть.**
  - Перевод есть у 24 из 26 актов, найденных поиском. Например, ПП-387 → `lex.uz/en/docs/8563448`.
  - Поэтому en-ссылка ведёт на перевод, а «(in Russian)» нужна только там, где перевода нет.
  - У переводов свои сокращения: RP-387 (ПП), DP-1 (УП), LRU-1181 (ЗРУ). Их надо учесть в глоссарии этапа 5.
- **Свежие акты из RSS.** Страница УП-236 через 5 дней после принятия не ссылается ни на узбекский оригинал, ни на дату вступления в силу. Если после страницы у акта нет узбекской версии, акт дополнительно ищется поиском. Дата вступления в силу из RSS при этом не стирается.
- **Страница документа** перечитывается, пока у акта нет даты вступления в силу или какой-то из версий. Так подхватываются переводы, появившиеся позже. Источник записи (`lex_rss` / `lex_search`) при дописывании со страницы не меняется.
- **Кэш 12 ч, а не 24.**
  - Ежедневный запуск в 09:30 иначе мог бы взять вчерашний ответ «не найдено», полученный на несколько секунд позже.
  - Кэш нужен для повторов в течение дня: `rerender`, ручной `verify-laws`.
  - В кэше хранятся строки выдачи и шапка документа без HTML. Ошибки не кэшируются.
- **Год рядом с номером.** Это правки `find_refs` этапа 3, найденные при ручной проверке.
  - «№ 440 от 2019 года» (только год) раньше не распознавался. Год брался по дате новости, и ПКМ-440 подтверждался чужим актом 2026 года. Теперь «от ГГГГ года» считается датой.
  - Дата за упоминанием другого акта ему не приписывается. Пример: «Қонун (ЎРҚ-419); ЎРҚ-1155-сон Қонун (22.06.2026)».
  - Если год всё же угадан (`year_guessed`), акт подтверждается, только если он принят не раньше чем за 60 дней до новости (`lex.guessed_year_days`). Иначе статус `pending`, а затем `not_found`.
- **Пересчёт окна заменяет упоминания материала.** Ключи, которых больше нет в материале (извлечение стало точнее), удаляются из `item_legal_refs`. У оставшихся статус сверки сохраняется.
- **Сверяются** упоминания в материалах окна, прошедших префильтр, а также все `pending` из прошлых окон. `not_found` ставится через 7 дней после публикации материала.
- **Для этапа 6** готовы:
  - `verify_window()` для конвейера;
  - `VerifyStats.became_verified` для блока «Обновления»;
  - `act_link(act, lang)` для ссылок.

### Замечания к следующим этапам
- **Этап 5 (QA).** Сравнивать название акта на lex.uz с темой новости: реквизиты могут сойтись, а акт оказаться чужим (ПКМ № 440, расхождение 2).
- **Этап 5 (глоссарий).** Добавить английские сокращения lex.uz: RP (ПП), DP (УП), LRU (ЗРУ).
- **Пилот.** У законов сквозная нумерация, без сброса по годам. ЗРУ без даты можно искать без года, и тогда ЗРУ-419 нашёлся бы однозначно. Сейчас такие упоминания уходят на ручную проверку.
- **Этап 8 (эксплуатация).** В штатной работе запросов меньше: найденные акты остаются в справочнике со всеми версиями и в следующие дни не запрашиваются. Повторно запрашиваются только акты без перевода или без даты вступления в силу. Сверка «с нуля» за понедельник (3 суток) — около минуты.
